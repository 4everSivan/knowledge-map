## 范围与方法

T03 在尚未发布的 v0.1.0 中接入工程制图指引，依据[工程制图设计](../docs/devel/design/06-工程制图.md)。实际批次为 `local-20261016-061219`，证据保留在 `local/acceptance/diagrams/local-20261016-061219/`。本轮全部工作在当前会话完成，没有启动子代理。

当前会话阅读七个受控原始文件，编写语义候选和 SVG，核对来源与表达，再使用宿主 Python 执行有限的 JSON/XML、类型属性、引用及哈希断言。检查命令没有作为脚本加入项目。样例不是独立宿主中的 `$km` 调用，不证明模型可以确定性地识别任意工程，也不证明样例业务实际运行。

## 原始材料与产物

样例由五个 Python 文件、一个部署声明和一篇原始领域说明组成。`submit()` 校验任务标识，记录 pending/running，等待 `execute()` 转换文本，保存结果后创建通知协程任务；ValueError 路径保存 failed。领域声明支持调度、执行和状态记录三个业务模块，通知是辅助职责。实体基数来自领域声明，部署图只表达配置声明。

最终受控集合位于批次的 `target/`：11 篇平铺中文 Markdown、8 份 SVG、8 份语义 JSON，及 manifest/尝试记录。文档、图稿和语义清单共有 27 个内容文件；manifest 在内容与引用检查后写入。术语卡是独立协议，本轮未为凑数量生成卡片。

| 图型 | 验证的含义 | 必要性 |
|---|---|---|
| 架构 | 三个模块的协作与状态写入方向 | 必需 |
| 流程 | 标识校验的真假分支 | 选配，正文可独立说明 |
| 时序 | 等待执行、结果返回、创建异步通知任务的顺序与方式 | 必需 |
| 状态 | 一次提交内的状态写入与 ValueError 条件 | 必需；另有文章选配复用 |
| 数据流 | 文本转换与经调度器保存结果的血缘 | 选配 |
| 实体关系 | Job 与 Attempt 的逻辑基数，不推断物理外键 | 选配 |
| 部署 | 声明的主机位置和单副本，不冒充运行实例 | 选配 |
| 依赖 | 调度模块指向执行与状态提供方 | 选配 |

语义先行的审阅及修正分别记录在 `semantic-review.json`、`semantic-corrections.json`。发现并修正了两份清单中的跨类别 ID 冲突，移除了无充分依据的实体键提示。`structure-final.json` 记录最终 SVG 与清单的实际 SHA-256；该批次较早的 `structure-results.json` 属于修图前记录，不作为最终字节凭据。

## 实际渲染

独立 SVG 使用已有 `rsvg-convert 2.62.3` 输出 1920 像素宽 PNG，再实际查看。Markdown 内嵌使用 macOS 上已有的 Typora `1.12.6 (7588)`，逐类打开候选文章并查看截图；保持该查看器现有主题和文章显示宽度。未安装额外依赖。最终 SVG 与预览候选字节一致，正式文章的相对图片路径另经实际文件检查；相同文件、查看器、字体和显示宽度条件下复用此次视觉证据，没有声称重新截图。

初次观察发现四类图的连线共用出口，实体关系图还使用了易误读的流向箭头。修正了出口和正交路由，去掉实体关系箭头，将状态失败标签明确为 ValueError。修后实际查看中文、箭头、标签、遮挡、边界及裁切，未发现这些样例中的可读性问题。修正记录在 `visual-repairs.json`；独立渲染图和修后总览保留在 `rendered/`，逐图环境及哈希记录在 `render-review.json`。Typora 截图由工具在会话内返回，没有伪造落盘截图路径。

浏览器不允许本地 file URL 预览，Quick Look 沙箱尝试退出 255；两者均未记为通过。独立 SVG 和 Markdown 的正式检查依据分别是上述本地渲染器与 Typora。未检查其它 Markdown 查看器、PDF、Word、网站或目标业务运行。

## 异常、更新与交付

| 场景 | 实际结果与证据 |
|---|---|
| 七组语义异常 | 在受控候选中分别注入悬空端点、缺证据、缺分支条件、重复时序顺序、未知调用方式、缺状态事件及非法基数；宿主断言均识别，未创建确认 manifest，见 `semantic-negatives.json` |
| 必需图检查未执行 | 构造明确标注为模拟的 `not_run` 回执；共享状态图有一处必需使用，仍阻止确认，见 `cases/required-not-run.json`；不是实际渲染器失败的证据 |
| 必需图渲染失败 | 对损坏的状态 SVG 实际调用渲染器，退出 1；确认清单哈希不变，见 `cases/required-render-failure/result.json` |
| 选配图暂缓 | 损坏的流程 SVG 实际渲染退出 1；在独立集合副本中移除全部当前图片引用和活跃索引，正文仍完整，原受管图对进入留存记录；候选继续标 failed，正式集合通过，见 `cases/optional-defer/` |
| 共享图必要性 | 状态图有必需与选配两处使用，整体保持必需，不能按选配暂缓，见 `scenario-results.json` |
| 无变化复用 | 实际比对七个来源及所有正式输出哈希，无内容写入，修订号保持 1；复用具有明确环境依据的视觉检查，见 `scenario-results.json` |
| 内部代码变化 | 在独立副本中将通知返回字典改为局部变量后返回；静态解析通过，来源哈希确有变化，经同会话契约审阅无需改图，8 份 SVG 和 8 份清单字节保持，见 `cases/scoped-update/` |
| 占用、外部修改与原始资产 | 实际构造未受管占用和受管哈希不符，保留原文件且不执行替换；生成图目录排除出事实输入，目录外的原始 SVG 保留，见 `scenario-results.json` |
| 实际中断及恢复 | 首次交付的链接断言在其它文章尚未落盘时提前运行，退出 1；观察到已写 20 个文件而 manifest 不存在，记录实际混合集合后停止。续跑核对来源、已写哈希与候选，完成 27 个内容文件，重新核对全部链接，最后写 manifest，见 `interrupted-attempt.json` 与 `recovery-result.json` |

早期一次内联样例准备命令因编码导致 SyntaxError，未产生产物；缩小命令后成功。以上失败均保留真实结果，没有以最终成功覆盖为“从未失败”。链接检查的修正只适用于本轮演练，未新增交付脚本。

## 开发检查与限制

发布资源包括英文 SKILL/workflow、按需参考、八类图型规则、静态 SVG 基础模板及固定上游提交的 MIT 声明。没有新增 km 运行脚本、网站、模型服务、自动布局器或旧库迁移。manifest/尝试/workflow 协议为 2.0，图稿清单、术语卡和配置各维持独立的 1.0 协议。

结构化异常检查是宿主对选定样例的有限断言，来源判断和可读性是当前会话的实际审阅；它们不等于通用校验器。尚未验证已安装宿主触发、大型工程完整发现、多查看器兼容、真实并发写入、文件系统故障注入或未实现目标图的实际渲染。真实中断只覆盖上述前向引用断言失败，不证明原子写入或自动回滚。

入口格式、英文执行资源、YAML/JSON、参考链接、模板 XML 和项目治理的最终结果由 T03 卡记录。T01/T02 是各自历史规则下的证据，不代替本轮协议与图稿验收。复跑建立新批次，不删除既有 `local/` 证据。
