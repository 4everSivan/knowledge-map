## 实际样例与分层产物

WorkDesk 样例有七个原始文件，入口从 `runner.main()` 进入任务分派。职责和调用关系支持三个业务模块：

| 模块 | 原始来源 | 对应候选 |
|---|---|---|
| 任务调度 | `tasks/dispatcher.py` 与 `policies/replay.py`，以及原项目说明 | 独立主设计和状态流转专题 |
| 任务执行 | `execution.py` 及原项目说明 | 独立主设计 |
| 状态记录 | `storage.py` 及原项目说明 | 内容简短但独立的主设计 |

`utils/text.py` 是未接入主链路的通用辅助函数，存在源码目录不成为独立业务模块的充分依据。三个模块的划分由原文档声明和实际调用共同核对。

完整候选包括 README、总体设计、三篇模块主设计、一篇模块状态专题和一篇复杂跨模块流程，共七篇中文 Markdown；另有一张“完成复用”术语卡，关联主设计、专题和流程。所有正式 Markdown 平铺，术语及状态 JSON 保持在 `.cards/`。
