# 本地使用与验证指南

> **created**: 2026-10-15 ｜ **last-change**: 2026-10-15 ｜ **status**: active

本项目是供宿主 AI 读取的 km 技能，没有应用服务、监听端口、数据库或构建步骤。实际运行资源为根目录 SKILL.md、workflow.yaml 与 references/，使用方式见[项目入口](../../README.md)。

## 1. 使用条件

宿主需要支持技能加载以及项目搜索、读取、编辑和差异查看。首次调用不要求用户配置模型 API Key、安装流程引擎或执行脚本。加载本目录时技能名为 km；已安装宿主中的实际发现、触发与 /km 适配尚未验证。

在目标工程调用 `$km`，或在请求中指定工程范围。产物为 docs/official/ 下的中文 Markdown 和 .cards/ 下的 JSON。中断或部分覆盖后重复调用同一入口，先核对记录与实际文件，再继续处理。

## 2. 本项目开发检查

在项目根运行既有治理检查：

```sh
scripts/adflow-verify --mode init --json
scripts/adflow-verify --json
```

技能基础检查可使用当前环境 skill-creator 的 quick_validate.py；它只检查入口格式，不能替代 workflow YAML 解析或语义演练。该工具不是 km 的分发依赖，详情见[验收说明](../../tests/acceptance.md)。

本机运行证据位于 local/acceptance/km-v0.1/，没有新建 km 运行脚本。样例业务入口未执行，不存在可据以记录的服务端口或健康检查；本项目无需部署实况报告。

## 3. 验证边界与恢复

覆盖不足、来源冲突或外部产物修改时，按 workflow 保留候选并报告，不把部分内容写成完整知识库。多文件编辑没有事务和自动回滚保证；中断后先逐项核对已写范围。仅能从可核实原文恢复，不能假定旧集合完整。

既有 local/ 资料不自动删除或重置。实际测试和任务进展分别见[验收说明](../../tests/acceptance.md)与[任务总账](../devel/task/index.json)。
