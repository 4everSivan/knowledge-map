# Upstream attribution and adaptation

Source: [cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design/tree/d97c5c7477e54cee17cfa6459190610da0643a05), fixed commit `d97c5c7477e54cee17cfa6459190610da0643a05`.

The shared style and eight type references adapt the upstream skill, style/layout guidance and `type-architecture`, `type-flowchart`, `type-sequence`, `type-state`, `type-data-flow`, `type-er`, `type-deployment`, and `type-dependency` references. This is a maintained local technical adaptation, not a complete upstream package or a guarantee of upstream compliance. No auto-update or runtime fetch is required.

Retained: semantic/type selection, restrained emphasis, spacing and orthogonal routing, readable labels, accessible SVG, and overview/detail splitting. Changed: direct static SVG for Markdown, local Chinese-capable system fonts, semantic lists with per-element evidence, km collection/ownership/recovery, dual-view rendering requirements, and scoped updates. Numeric complexity limits are split prompts, never grounds to remove required facts. Unknown values are not filled to match a specimen.

Excluded: onboarding/profile approvals, brand scraping, HTML page wrappers, animations, gallery, import/export commands, scripts and browser dependencies. In particular, no upstream geometry or rendered-layout checker ships with km; host checks and visual review must report their actual limits. The base SVG uses km-local styles and must be adapted to the target figure.
